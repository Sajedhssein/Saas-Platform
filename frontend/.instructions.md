# Frontend API Integration Instructions

## Overview
This is a React + TypeScript frontend that connects to a Laravel SaaS backend API using Axios. The backend is located at `c:\Users\User\OneDrive\Desktop\backend` and runs on `http://127.0.0.1:8000`.

## Axios Configuration
The axios client is configured in `src/api/axios.ts` with:
- **Base URL**: `http://127.0.0.1:8000/api` (configured via `VITE_API_URL`)
- **Token Management**: Automatically adds JWT Bearer token from `localStorage.getItem('token')`
- **Error Handling**: Redirects to `/login` on 401 Unauthorized
- **Request Interceptor**: Adds Authorization header with stored token

## Available Backend Endpoints

### Authentication (`/auth`)
- `POST /auth/register` - Register company admin
- `POST /auth/login` - Login user
- `POST /auth/logout` - Logout user
- `GET /auth/me` - Get current user
- `POST /auth/refresh` - Refresh JWT token

### Projects (`/projects`)
- `GET /projects` - List all projects
- `POST /projects` - Create new project
- `GET /projects/{id}` - Get project details
- `PUT /projects/{id}` - Update project
- `DELETE /projects/{id}` - Delete project

### Tasks (`/tasks`)
- `GET /tasks` - List all tasks
- `POST /tasks` - Create new task
- `GET /tasks/{id}` - Get task details
- `PUT /tasks/{id}` - Update task
- `DELETE /tasks/{id}` - Delete task
- `PUT /tasks/{id}/status` - Update task status

### Task Files (`/tasks/{taskId}/files`)
- `POST /tasks/{taskId}/files` - Upload file (FormData)
- `DELETE /tasks/{taskId}/files/{fileId}` - Delete file
- `GET /tasks/{taskId}/files/{fileId}/download` - Download file

### Task Comments (`/tasks/{taskId}/comments`)
- `GET /tasks/{taskId}/comments` - List comments
- `POST /tasks/{taskId}/comments` - Add comment
- `DELETE /tasks/{taskId}/comments/{id}` - Delete comment

### Task Responses (`/tasks/{taskId}/responses`)
- `GET /tasks/{taskId}/responses` - List responses
- `POST /tasks/{taskId}/responses` - Submit response
- `DELETE /tasks/{taskId}/responses/{id}` - Delete response

### Employee Management (`/employees`)
- `GET /employees` - List all employees
- `POST /employees` - Create new employee
- `PUT /employees/{id}` - Update employee
- `DELETE /employees/{id}` - Delete employee

### Notifications (`/notifications`)
- `GET /notifications` - List notifications
- `PUT /notifications/{id}/read` - Mark as read
- `DELETE /notifications/{id}` - Delete notification

### Reports (`/reports`)
- `GET /reports/performance` - Performance reports
- `GET /reports/activity-logs` - Activity logs

## How to Use

### 1. Import axios
```typescript
import api from '@/api/axios';
```

### 2. Make API Calls

**GET Request:**
```typescript
const response = await api.get('/tasks');
const tasks = response.data.data;
```

**POST Request:**
```typescript
const response = await api.post('/tasks', {
  title: 'New Task',
  description: 'Task description',
  project_id: 'uuid',
  assigned_to: 'user_id'
});
```

**PUT Request:**
```typescript
const response = await api.put(`/tasks/${taskId}`, {
  title: 'Updated Task',
  status: 'in_progress'
});
```

**DELETE Request:**
```typescript
await api.delete(`/tasks/${taskId}`);
```

### 3. Handle Responses
```typescript
try {
  const response = await api.get('/tasks');
  const { success, data, message } = response.data;
  
  if (success) {
    console.log('Data:', data);
  }
} catch (error) {
  console.error('Error:', error.response?.data?.message);
}
```

### 4. File Upload (Multipart FormData)
```typescript
const formData = new FormData();
formData.append('file', file); // from input type="file"
formData.append('description', 'File description');

const response = await api.post(`/tasks/${taskId}/files`, formData, {
  headers: {
    'Content-Type': 'multipart/form-data'
  }
});
```

## Common Patterns

### When Creating Components
1. Use the axios client from `src/api/axios`
2. Store token in `localStorage` after login (key: `token`)
3. Handle 401 errors gracefully (user will be redirected to login)
4. For lists, use GET; for creation, use POST; for updates, use PUT; for deletion, use DELETE

### When Working with Dates
- All dates from backend are ISO 8601 format
- Use filtering: `GET /tasks?date_from=2026-01-01&date_to=2026-12-31`

### Error Response Format
```typescript
{
  success: false,
  message: "Error message",
  errors?: {
    field_name: ["error 1", "error 2"]
  }
}
```
